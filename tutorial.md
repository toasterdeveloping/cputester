# how to use
since the package might be available on the AUR (Arch User Repository) i'll recommend you first install it

# help command
since its a terminal based tool, if you use ``cputester -h`` it will give you a list of commands to use

# tutorial for testing
if you have a raw binary file you can use cputester to test it, if we assume that the file is named "program.bin" you would use the command ``cputester program.bin``
it can also generate the logs folder where you can check logs that were created during the execution.
